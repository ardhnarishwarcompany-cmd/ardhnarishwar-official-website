## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/ardhnarishwarcompany-cmd/ardhnarishwar-official-website.git
```

### Navigate to Project

```bash
cd ardhnarishwar-official-website
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

## 📦 Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
